# Glossari de Git i GitHub

Glossari col·laboratiu creat per la classe. Cada terme és un fitxer dins la carpeta [`termes/`](termes/).

## Com està organitzat

- `termes/_plantilla.md`: plantilla que has de copiar per crear un terme nou.
- `termes/<nom-del-terme>.md`: un fitxer per terme, en minúscules i amb guions.

## Vols contribuir?

Llegeix [CONTRIBUTING.md](CONTRIBUTING.md). En resum: issue → fork → branca → Pull Request → code review → merge.
